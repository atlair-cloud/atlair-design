# Atlair Design

Atlair's open-source Vue 3 design system: design tokens and accessible components built on
[Reka UI](https://reka-ui.com) and Tailwind CSS 4, following [Base UI](https://base-ui.com)'s API
conventions.

Status: planning. See [docs/plan.md](docs/plan.md) for the primitives choice, packages, component
roadmap and the practices every component meets.
